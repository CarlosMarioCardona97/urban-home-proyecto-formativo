# RF07 - Sistema de mensajería

## Objetivo

Permitir la comunicación directa entre arrendatarios y arrendadores dentro de Urban Home.

## Descripción

El sistema debe ofrecer mensajería interna para que los usuarios puedan comunicarse sin intermediarios sobre los inmuebles publicados.

## Criterios de aceptación

- Los arrendatarios y arrendadores pueden enviar y recibir mensajes directos.
- Los mensajes se entregan en tiempo real o en un máximo de cinco segundos.
- El sistema notifica a la persona cuando recibe un mensaje nuevo.
- El historial de conversaciones se conserva y puede consultarse en cualquier momento.

## Estado

En análisis y documentación.
