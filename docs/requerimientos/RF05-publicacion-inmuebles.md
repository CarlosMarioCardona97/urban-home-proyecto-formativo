# RF05 - Publicación de inmuebles

## Objetivo

Permitir que los propietarios publiquen inmuebles disponibles en Urban Home.

## Descripción

El sistema debe permitir que un propietario registre y publique un inmueble con la información necesaria para que pueda ser consultado por otros usuarios.

## Datos obligatorios

- Precio.
- Tipo de inmueble: casa, apartamento, apartaestudio o local.
- Área.
- Fotografías.
- Ubicación exacta.

## Criterios de aceptación

- El sistema exige los datos obligatorios antes de publicar.
- El propietario puede cargar al menos tres fotografías del inmueble.
- El inmueble publicado se hace visible en la plataforma.
- El sistema muestra un mensaje de error cuando falta información obligatoria.

## Estado
