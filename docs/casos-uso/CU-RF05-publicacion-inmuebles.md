# CU-RF05 - Publicación de inmuebles

## Actor principal

Propietario de un inmueble.

## Precondición

El propietario tiene una cuenta activa e inició sesión en Urban Home.

## Flujo principal

1. El propietario selecciona la opción de publicar inmueble.
2. Ingresa el precio, tipo de inmueble y área.
3. Agrega la ubicación y las fotografías requeridas.
4. El sistema valida que todos los datos obligatorios estén completos.
5. El propietario confirma la publicación.
6. El sistema registra el inmueble y lo muestra en la plataforma.

## Resultado esperado

El inmueble queda publicado y disponible para consulta de los usuarios.

## Escenarios alternativos

- Si falta un dato obligatorio, el sistema informa qué campo debe completarse
