# Urban Home - Proyecto formativo

## Descripción

Urban Home es un proyecto orientado a la gestión de propuestas técnicas de software. Este repositorio registra el desarrollo del proyecto, sus requerimientos funcionales y el control de cambios realizado mediante Git y GitHub.

## Objetivo

Aplicar un flujo de trabajo de control de versiones que permita desarrollar funcionalidades en ramas independientes, registrar cambios mediante commits claros e integrar los resultados a la rama principal mediante revisión.

## Estrategia de ramas

- `main`: contiene la versión integrada y estable del proyecto.
- `feature/RFxx-descripcion`: contiene el desarrollo de un requerimiento funcional específico.

Cada requerimiento se trabajará en una rama independiente. Al finalizar su desarrollo, se creará un Pull Request para revisar los cambios antes de fusionarlos con `main`.

## Flujo de trabajo

1. Crear una rama para un requerimiento funcional.
2. Realizar cambios pequeños y organizados.
3. Crear commits con mensajes claros y descriptivos.
4. Crear un Pull Request hacia la rama `main`.
5. Solicitar revisión de un compañero.
6. Fusionar los cambios aprobados a `main`.

## Evidencias

El historial de commits, las ramas y los Pull Requests de este repositorio constituyen la evidencia del proceso de control de versiones aplicado al proyecto Urban Home.
